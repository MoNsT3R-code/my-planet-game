# Planet Pepper

A tiny-planet delivery adventure, built in 3D with Three.js. It runs in the browser as one HTML file.

Pepper runs errands on the smallest planet in the sky. Deliver parcels before they're late, round up runaway animals, find hidden stars and beat the robots in Hobby Park. Watch out for traffic, though: every bump costs a heart.

## How to play

Clone or download this repo and open `index.html` in any modern browser (Chrome, Edge, Firefox or Safari). You don't need to install or build anything.

## Features

- **Five levels** on one tiny planet, with traffic that gets faster and busier each level
- **Missions** against the clock: parcel deliveries, runaway animals, hidden stars and Hobby Park minigames
- **Combo scoring**: grab coins and stars in quick succession to multiply your points
- **Shop**: spend coins on bike colours, outfits and hats
- **Day and night** cycle, a planet map, music and sound effects
- **Saves locally**: your high score, coins and best level are kept between sessions
- **Plays on phones** with an on-screen arrow pad

## Controls

| Action | Keys |
| --- | --- |
| Walk | WASD / arrow keys, or click where you want to go |
| Run | Shift |
| Hop on the bike | R |
| Interact with buildings / Hobby Park spots | E (or click) |
| Map | M |
| Switch day / night | N |
| Pause | Esc |

## Rules

- Finish every mission on the list before the clock runs out to clear the level. The **gold arrow** points to your next goal.
- **Parcels:** pick one up at the Post Office and drop it at the glowing building before its timer runs out.
- **Animals:** runaways have a red **!** above them. Walk into one to catch it, then lead it back to the farm field.
- **Cars:** each hit costs a heart, and you have three.

## Built with

- HTML, CSS and JavaScript
- [Three.js](https://threejs.org/) for 3D graphics
- Web Audio API for sound
